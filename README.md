# 赛鸽血统环号登记站

运行：

```bash
npm start
```

访问`http://localhost:3024`。支持档案、血统查询、转让和归巢成绩记录。

## 奖金结算台

访问`http://localhost:3024/settlement`。按「足环 + 放飞日 + 名次」为每场比赛生成应发奖金：

- 收款人取放飞日当天有效的鸽主，比赛后才登记的转让不影响已算出的收款人。
- 重复结算不会重复发钱：榜单无变化时不产生新版本。
- 成绩更正或取消后重新结算，自动算出新应收和待追回；旧结算版本留档可查，不再付款。
- 页面可登记赛事奖金方案、查看每笔应收、待追回和异常记录。

代码拆分：

- `prizeRules.js` — 奖金判定：比赛日鸽主回放、应发计算、新旧版本差额与追回。
- `settlementStore.js` — 档案存储：JSON 读写、奖金方案登记、结算版本留档。
- `settlementPage.js` — 页面操作：结算台页面与交互。
